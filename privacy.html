プライバシーポリシー

最終更新：2026 年 11 月 26 日

  • Erin-local は、開発者本人だけが使う個人用のアプリです。
  • Google のアカウントからは、Gmail とカレンダーを読み取るだけです（gmail.readonly・calendar.readonly）。メールの送信・削除や、予定の書き換えはしません。
  • 読み取った内容は、開発者の Mac の中だけで処理し、保存します。
  • 読み取った内容を第三者に渡したり、販売したり、広告に使ったりしません。
  • Google API から受け取った情報の使用は、限定的使用の要件を含む Google API Services User Data Policy に従います。
  • アクセスは、Google アカウントの「サードパーティのアプリとサービス」からいつでも取り消せます。

Privacy Policy

Last updated: November 26, 2026

  • Erin-local is a personal app used only by its developer.
  • It only reads Gmail and Google Calendar (gmail.readonly, calendar.readonly). It never sends or deletes mail or changes events.
  • Data it reads is processed and stored only on the developer's own Mac.
  • Data is never shared with third parties, sold, or used for advertising.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time from "Third-party apps & services" in the Google Account.
